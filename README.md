## Future Scope

PayLock can be expanded into a complete decentralized freelance escrow platform.

Future improvements include:

- Multiple escrow agreements for different freelance projects.
- Milestone-based payments for projects with multiple stages.
- Freelancer acceptance before an escrow becomes active.
- Refund and cancellation functionality.
- Dispute resolution mechanisms.
- Support for multiple Stellar-based tokens.
- Transaction history and escrow status tracking.
- Freighter wallet integration.
- A web frontend for clients and freelancers.
- Notifications for escrow deposits and payment releases.
- Improved authorization and security checks.
- Additional automated tests and security auditing.
- Production-ready deployment after security review.

The long-term goal is to provide a transparent and easy-to-use escrow platform for freelance clients and freelancers using Soroban smart contracts on Stellar.
